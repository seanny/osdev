# Untitled OS

Welcome to my untitled OSDev project. This project is focused on learning how modern operating systems work from the ground up.

The project does not currently have a permanent name. `Untitled OS` will remain its working title until I find one that fits.

## About

Untitled OS is intended to explore OS design and development whilst taking inspiration from both Unix-lime systems and Windows NT. The goal is not to reproduce either OS exactly but to study the strengths and weaknesses of both and combine them into one OS. The exact architeture is still being decided.

## Project Goals

The primary goal of Untitled OS is learning.

This project exists as a way for me to understand operating systems by designing and implementing one myself rather than treating the OS as a black box.

As a result:
- Correctness and understanding is more important than rapid development.
- Components may be rewritten as my understanding improves.
- Experimental designs are expected.
- Compatibility with existing operating systems is not currently a primary goal.
- The project may choose educational value over practicality use.

Untitled OS should eventually become a usable system, but becoming a production operating system is not the immediate objective.

## AI Usage

This project is intentionally developed with little to no AI involvement.

The purpose of Untitled OS is to learn operating-system development directly, so kernel code, architecture decisions, algorithms, and other educationally important parts of the project are intended to be written and understood by me.
