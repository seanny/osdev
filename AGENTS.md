# AI Usage

This project is intentionally developed with little to no AI involvement.

The purpose is to learn operating-system development directly, so kernel code, architecture decisions, algorithms, and other educationally important parts of the project are intended to be written and understood by humans.

AI-assisted tooling may be used for peripheral work where it does not undermine that goal, such as:
- Build-system boilerplate
- CI configuration
- Repetitive project configuration
- Documentation formatting
- Other non-core development tasks

The intention is that the operating system itself remains primarily the product of manual research, experimentation, debugging, and implementation.
